## Overview
The inherently chaotic and multi-scale nature of the atmosphere imposes strict limits on forecast predictability. Small initial errors at convective scales rapidly accumulate and cascade upward, driving large-scale error growth. This project explores these scale interactions by comparing the performance of different Data Assimilation (DA) schemes in constraining downscale and upscale error propagation.

**Key Features:**
* Implementation of the Lorenz '96 single-layer and two-layer idealized models.
* A fully partitioned Fraternal Twin OSSE framework (Nature Run, Simulated Observations, Free Run).
* Comparative analysis of DA schemes, focusing on standard 3D-Var, incremental 3D-Var, and Optimal Interpolation (OI).
* Evaluation of "downscale control" and "upscale control" across spatial scales.

## Methodology

### The OSSE Setup
The experiments follow a Fraternal Twin setup to mimic real-world observing systems:
1.  **Nature Run:** Acts as the "true" state of the atmosphere, integrated over a sufficiently long period (e.g., 50 MTU) to achieve climatological balance.
2.  **Simulated Observations:** Generated by applying an observation operator (an identity matrix in this setup) to the Nature Run, with added Gaussian noise to simulate instrument error.
3.  **Free Run:** An unconstrained forecast acting as the baseline.

### Data Assimilation Schemes
The repository evaluates how well different schemes assimilate observations across scales:
* **Optimal Interpolation (OI):** Utilized for baseline localized updates.
* **3D-Var & Incremental 3D-Var:** Implemented using analytical matrix inversion and the iterative L-BFGS-B solver. Because the fully observed network results in a strictly linear observation operator, both standard and incremental 3D-Var configurations are tested and compared.
